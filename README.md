# WIFI CONTROL WEB — v0.1.0

Proyecto web independiente del proyecto original WIFI CONTROL Flutter.

## Probar en computadora
1. Abre este sitio desde un navegador moderno.
2. Selecciona los módulos para revisar la navegación.

## Probar en iPhone o Android
Abre el sitio publicado mediante HTTPS. En iPhone puedes usar Compartir → Añadir a pantalla de inicio.

## Estado actual
Este es un prototipo visual navegable. Todavía no se conecta a routers ni detecta dispositivos reales. Los navegadores móviles restringen el escaneo LAN y el acceso a interfaces administrativas; esas capacidades necesitan una integración compatible y pruebas específicas.

## Publicación
GitHub Pages publica el contenido de la raíz de la rama main.
